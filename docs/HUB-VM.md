# 用一台 Windows 虚拟机当 Hub

目标：**Bot 在 VM 里干活**（开网页、跑命令、存文件），你在**自己的电脑和手机**上发消息、看结果。
这台 VM 就是"闲置电脑/云主机"的替身；将来换成真机器，步骤一模一样。

```
你的电脑 / 手机  ──局域网──▶  Windows VM（Hub）
  Desk 客户端                 Desk.exe --hub
  （或浏览器 + 配对码）         Bot 进程 · 浏览器 · 文件 · 例程
```

---

## 一、VM 这边（一次性配置）

### 1. 网络必须是"桥接"

| 虚拟化软件 | 设置 |
|---|---|
| VMware Workstation/Player | 虚拟机设置 → 网络适配器 → **桥接（Bridged）**，勾"复制物理网络连接状态" |
| VirtualBox | 设置 → 网络 → 连接方式 **桥接网卡**，界面名称选你实际上网那块 |
| Hyper-V | 虚拟交换机管理器 → 新建**外部**虚拟交换机 |

NAT 也能用，但要手动做端口转发，桥接省事。桥接后 VM 在路由器上和你的电脑**同级**，互相能直连。

### 2. VM 里装 Desk

把 `Desk-Setup-1.0.0.exe` 拷进 VM，双击安装（装到当前用户，不需要管理员）。装完先别启动。

### 3. 用 Hub 模式启动（无窗口）

```bat
"%LOCALAPPDATA%\Programs\Desk\Desk.exe" --hub
```

- 没有界面，只在托盘里；**服务监听 0.0.0.0:4390**
- 首次运行会在黑窗口里打印 `LAN URL` 和 `pairing code`（配对码也能在客户端设置页看到）
- 想换端口：`set PORT=4390` 后再启动

> 不想安装？把 `Desk-Portable-1.0.0.exe` 拷进 VM，用 `Desk-Portable-1.0.0.exe --hub` 也可以，免安装。

### 4. 放行防火墙

```bat
netsh advfirewall firewall add rule name="Desk Hub" dir=in action=allow protocol=TCP localport=4390
```

（管理员命令提示符里执行一次即可。）

### 5. 记下 VM 的地址

```bat
ipconfig
:: 找 IPv4 地址，例如 192.168.1.57
```

### 6. VM 不要睡眠

设置 → 系统 → 电源 → 屏幕和睡眠 → **从不**。Hub 睡了就联系不上。

### 7. （可选）开机自启

任务计划程序 → 创建任务：

- 触发器：**登录时**
- 操作：启动程序 `"%LOCALAPPDATA%\Programs\Desk\Desk.exe"`，参数 `--hub`
- 勾选"不管用户是否登录都要运行"需要密码；只在登录时运行更简单（VM 设自动登录即可）

## 二、你的电脑这边

### 方式 A：用安装好的 Desk 客户端（推荐）

1. 打开 Desk
2. 菜单 **Desk → 切换到别的 Hub…**
3. 填 `http://192.168.1.57:4390` → 连接
4. 通过探活后会记住，**下次启动直接连它**；菜单里有"回到本机模式"

### 方式 B：浏览器

打开 `http://192.168.1.57:4390` → 输入 8 位配对码 → 进入工作台（和桌面端一模一样）。

### 方式 C：手机

同一 Wi-Fi 下，浏览器打开同一个地址 + 配对码。想"装到主屏"需要 https（Tailscale / Cloudflare Tunnel），局域网 http 不满足 PWA 条件。

---

## 三、验证是否真的通了

在**你的电脑**上：

```bat
curl http://192.168.1.57:4390/api/health
```

- 返回 `{"ok":true,...}` → 网络通、服务活着
- 返回 `AUTH_REQUIRED` → 网络通，只是还没配对（正常，去界面里配对即可）
- 连不上 → 看下面排错

然后在客户端发一句"列一下工作区文件"。它应该**只在 VM 的硬盘上**操作，你在本机看不到任何新进程——这就是"远程主机在干活"。

---

## 四、排错

| 现象 | 原因 / 解法 |
|---|---|
| 客户端连不上、curl 超时 | VM 网络是 NAT。改成**桥接**；或确认 VM 和电脑在同一网段（前三位相同） |
| `ping` 通但连不上端口 | 防火墙。在 VM 里执行上面的 `netsh` 放行命令 |
| 能连上、界面卡在"连接你的 Desk" | 配对码错 / 过期。码在 VM 的控制台输出里，或客户端设置页 |
| 连接成功但对话没反应 | VM 里没配模型。打开客户端 → 设置 → 填 provider/baseUrl/model/key（key 存在 VM 上） |
| VM 重启后客户端白屏 | Hub 没起来。把 `--hub` 做成开机自启；或先手动启动一次 |
| 手机连不上 | 手机和 VM 不在同一网段（比如手机走 4G）。用 Tailscale 或隧道 |

## 五、以后换成"真·闲置机器/云主机"

把第 1 步换成"插网线拿到局域网 IP"，其余完全一样。

云主机（Linux）不用 `--hub`，直接：

```bash
HOST=0.0.0.0 ASSIST_ALLOW_REMOTE=1 PORT=4390 node src/server.mjs
# 或 hub/desk-hub.service / hub/docker-compose.yml
```

公网访问**不要**直接开 4390，用 Tailscale 或 Cloudflare Tunnel。

---

## 六、数据在哪

VM 上：`%APPDATA%\Desk\`（配置、记忆、会话、技能、工作区、浏览器登录态）。
想备份/迁移，整个目录拷走即可；换机后客户端重新配对一次。
